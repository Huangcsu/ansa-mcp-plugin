旧 79 项是迁移功能对应的统计口径，当前 65 项是 MCP 注册工具数。各项按限定场景核验，不能用两者的数量宣称覆盖全部实体、deck 或工程场景。

## 2026-10-20 启动模型状态读取

后端与桥接认证握手后自动排入只读探测，模型读取仍在 ANSA 主线程执行。等待主线程时保持单个在途请求；明确执行错误有限退避重试，最多三次；重连及迟到回调按连接代次隔离。自动探测不创建目标绑定或执行授权。面板区分读取中、等待响应、已识别与失败，并标记快照读取时间及执行前校验。

该阶段全量 **448 项单元通过**；**65 工具**的真实 MCP stdio／TCP／SQLite 模拟通过，并新增“仅初始化和发现工具、尚未查询模型便已自动探测，且仍未授权”的断言。面板审查发现的绑定期间断线旧提示残留已修复并覆盖同后端重连。该阶段未连接用户 ANSA、未热加载现有实例；后续布局阶段另有以下独立真机验证。

## 2026-10-20 控制面板布局调整

概览改为分组标签，合并当前窗口与 AI 目标相同时的重复信息；其他目标单独提示。完整路径、进程、会话、后端标识及代次移到诊断页。主按钮统一中文，增加诊断快捷入口，诊断长行按窗口换行。状态缓存仅用于展示，身份核对及执行前校验继续生效。布局说明见[实施记录](reference/panel-overview-plan.md)。

最终全量 **454 项单元通过**，**65 工具**的 MCP stdio／TCP／SQLite 模拟通过。覆盖旧快照、同后端重连、其他窗口目标的模型及求解器信息、授权与绑定代次，并验证原生控件更新及关闭后的回调保护。

在隔离运行目录启动独立 ANSA 2026.1.0，验证自动读取成功但尚未授权、主动连接、暂停、恢复和诊断切换。生产按钮通过官方 `BCButtonRunClickFunction` 在 ANSA 主线程调用；逐步核对实际状态与原生窗口截图。当前 200% 显示缩放下，常规 1026×791 与紧凑 862×787 窗口均完整显示概览，诊断长行换行。README 截图来自该独立实例。

本轮没有运行建模、保存或删除模型的 API，没有热加载用户现有实例；未验证物理鼠标、键盘遍历、屏幕阅读器或其他 DPI。以上证据不扩展为业务模型写入或所有显示环境的验收。

## 已知限制

- 目标尺寸不等于所有边都严格等长；回包需检查实际边长、拓扑和范围覆盖。
- Map 六面体目标层长模式限定可确认的平行端面与直扫掠，复杂体和曲面不由该证据覆盖。
- 接触距离及节点采样不等于物理面积覆盖，也不能代替求解器的 TIE 或接触有效性判断。
- 机构定义与配置检查不代表已经完成运动或动力学求解。
- 既有一次机构组合夹具出现过原生进程退出，根因尚未确认；专用机构夹具的通过不能消除这项稳定性风险。
- 依赖锁目前固定版本但没有下载哈希；不同安装环境和后续发行物仍需独立核验。

原始报告、失败轮次、模型和截图保留为本机维护材料，不随公开仓库分发。本页不提供无法从公开检出访问的日志链接。
