# 发布说明

本项目从单一源码仓库构建外部服务和 ANSA 原生桥接。版本以 `pyproject.toml` 及配套构建脚本为准；当前为 `0.1.0` 预览版。

## 源码范围

公开仓库包含三包源码、有效测试与自制夹具、开发和构建脚本、原生入口、依赖清单、MIT 许可及公开文档。

个人智能体配置（`.agents/`、`AGENTS.md`）、构建目录、运行控制数据、本机报告、用户模型、官方 SDK、API 索引和内部维护档案不进入源码或安装包。源码交付以明确的 Git 提交为输入，不从本机工作目录整包复制。

## 发行步骤

1. 确认工作树和提交范围，运行适当回归、映射生成及文档链接检查。
2. 从干净检出构建外部 wheel 与原生源码暂存，核对包内容和 MIT 许可。
3. 用官方 Packager 生成 `.bpkg`，记录构建提交、工具版本、文件清单及 SHA256。
4. 在独立环境安装对应产物，验证 MCP、面板绑定、模型写入/幂等、保存重开、独立回读和所属窗口。
5. 将对应提交打版本标签，并在 GitHub Release 附上配套产物、校验清单、安装说明和已知限制。

GitHub 源码仓库为 [Huangcsu/ansa-mcp-plugin](https://github.com/Huangcsu/ansa-mcp-plugin)，默认分支为 `main`。发布时明确选择公开分支和标签，避免把本机维护分支一并上传。

## 配套产物

| 产物 | 内容 |
| --- | --- |
| 外部 wheel | `ansa_mcp_plugin`、`ansa_mcp_shared`、发行元数据与许可 |
| 官方 `.bpkg` | `ansa_mcp_bridge`、同版共享包、原生入口与许可 |
| 安装配套文件 | 安装器、运行依赖锁、简要安装说明和各文件校验值 |

构建和安装命令见[安装说明](installation.md)。既有候选的通过记录不自动适用于重新打包的产物；新产物的验证结果单独记录。
